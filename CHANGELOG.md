# Changelog

All notable changes to My Planner will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

## [1.0.0] - Unreleased

### Added

- Data recovery screens, raw-data downloads and preservation of existing data during recovery.
- Safe JSON import with validation, replacement confirmation and a backup before replacing a board.
- Cross-tab updates and conflict handling to protect against stale edits.
- Planning workflow across Today, the Now card, timeline, task board, week planner and calendar day plans, including copying tasks to selected days.
- Focus mode with a timer and quick add for capturing tasks.
- Recurring tasks, checklists, 64 optional life templates, editable areas, goals and quotes.
- Optional onboarding and weekly scoring with commitments and reviews.
- JSON backup export and restore while retaining the existing storage key and backup format.

### Changed

- Branding to My Planner, with a cobalt and sun favicon, updated manifest, PDF metadata and exported filenames.
- Accessibility and responsive layouts, including keyboard navigation, focus visibility and smaller-screen planning views.
- Documentation for local use, privacy, backups, testing and static deployment.

### Fixed

- Printable PDF tracker layout, page sizing, text handling and preview/export consistency across day, week, month and year sheets.
